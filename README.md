# AI Laboratory - Solutions

This repository contains the solutions and implementations for the
**Artificial Intelligence Lab** exercises.

## Labs-

### 1. Neural Models

Covers the basics of neural network learning and representation,
including: - XOR problem and neural network implementation - Forward
propagation and backpropagation - Gradient computation and analysis -
Effect of network depth - Sigmoid, Tanh, and ReLU activation functions -
Output layers and multi-class classification - Softmax and cross-entropy
based learning - Experiments with parameter initialization and symmetry

### 2. Agents

Covers the probabilistic formulation of language generation,
including: - Chain-rule factorisation of sequences - First-order and
higher-order language models - Conditional transition probabilities -
Greedy text generation - Sampling-based generation - Handling unseen
transitions - Probability normalization - Effect of additional context
on prediction - Comparison between deterministic and stochastic
generation

### 3. Search and A\*

Covers classical state-space search and heuristic search techniques,
including: - Warehouse robot navigation - Breadth-First Search (BFS) -
A\* search algorithm - Manhattan and Euclidean heuristics - Heuristic
comparison and node expansion - Path reconstruction - Solvable and
unsolvable search instances - Comparison of search efficiency under
different heuristics

### 4. Logical Planning

Covers automated planning using logical states and actions, including: -
Representation of states using logical propositions - Action
preconditions and effects - Add and delete effects - Move, pickup, and
drop actions - State-space planning using BFS - Plan reconstruction -
Independent plan verification - Handling impossible goals and irrelevant
actions - Basic Prolog-based logical reasoning and plan verification

### 5. Bayesian Networks

Covers probabilistic reasoning and probability factorisation,
including: - Chain-rule factorisation - Conditional probability -
Independence assumptions - Bayesian-network style reasoning -
Probability tables and transition relationships - Understanding how
probabilities are computed and represented - Reasoning about
dependencies between variables

## Repository Structure

Each lab is organized with the files required for its implementation and
documentation.

Depending on the laboratory, the repository may contain:

-   Python source files (`.py`)
-   Prolog programs (`.pl`)
-   README/documentation files
-   Test cases and verification code
-   Experimental implementations and supporting files

## Academic Use

This repository is maintained for **academic and laboratory
coursework**. The implementations and experiments are intended for
learning, demonstration, testing, and evaluation of the concepts covered
in the respective AI laboratories.
